Accessibility Statement

Last updated August 29, 2026

Damara Cohn and Mangrove Realty, Inc. are committed to making damaracohn.com usable by as many people as possible, including people who use assistive technology such as screen readers, screen magnification, voice recognition, or keyboard-only navigation.

Standard We're Working Toward

We use the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA as our reference standard — the same benchmark most businesses and courts point to for web accessibility in the United States. This is a goal we work toward continuously, not a one-time certification; there is no official government "ADA compliant" seal for a website to display, so this statement — rather than a badge — is our way of being transparent about where things stand.

What We've Done

  • Every page has a single, clearly structured main heading, with section headings organized in logical order underneath it.
  • A "Skip to main content" link is available at the top of every page for keyboard users, so the navigation menu doesn't have to be tabbed through on every visit.
  • Text and background color combinations are checked against WCAG's minimum contrast ratios (4.5:1 for normal text).
  • Images carry descriptive alternative text, and form fields carry an associated label, so screen readers can announce them correctly.
  • The site does not rely on an accessibility overlay or widget as a substitute for these fixes — those tools are not a reliable stand-in for accessible code, so we address issues directly in the site itself.

Known Limitations

This site is regularly updated with new pages and content, and we review each addition against WCAG 2.1 AA, but no website is ever "finished" on accessibility. If you encounter a page, image, form, or interactive element that doesn't work well with your assistive technology, we want to know about it and will prioritize a fix.

Third-Party Tools

Some tools on this site — including the property search, embedded lead-capture forms, and video content — are provided by outside platforms (including Mangrove Realty's IDX search and Google Forms). We've chosen established, widely used vendors, but we don't control their code directly; if you run into an accessibility barrier on one of these embedded tools specifically, let us know and we'll follow up with that vendor as well.

Feedback and Contact

If you have trouble accessing any part of this site, please tell us the page, what you were trying to do, and what happened — we'll do our best to fix it promptly. Reach us at damara@mangroverealty.com or by calling/texting (561) 637-4559.
